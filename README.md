# Blinkit Sales Dashboard

## Description
I made a special dashboard for Blinkit to look at how they are selling things. This dashboard is really good at showing sales trends and other important information about the stores and the things they sell. It is also very easy to look at and understand.

## Purpose
The main reason I made this project is to take a lot of sales information and turn it into something that can actually help people make decisions. It helps us see how things are selling and which stores are doing well. We can also see which things are popular and where they are selling them.

## Key Features
- You can pick which store location and what kind of things you want to look at.
- There are cards that show how much everything sold for and how many things were sold.
- We can see how sales are going up or down over time, for each store.
- We can look at what kinds of thingsre selling well and where.
- We can compare how different stores are doing.
- We can see which kinds of things are selling well in each store.
- The dashboard is very easy to use. It looks like Blinkits website.
- I used Power BI to make it. It has a lot of special features.

## Tools Used
- Power BI
- DAX
- Data Modeling
- Data Visualization
